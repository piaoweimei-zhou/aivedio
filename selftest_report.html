四、发现的问题

✅ 已修复（阻断性 · 已现场修复并复测通过）

B1 · /api/director/stages/execute 对任意阶段返回 500

根因：api/director_stage_api.py:128 中 task = task_mgr.create_task(...) 未 await——create_task 是协程方法，返回的是 coroutine 而非任务对象，下一行 task.task_id 抛 AttributeError。由于是共享提交路径，该 bug 会让前端所有 AI 生成（文生图/分镜/精修/视频/剪辑/导出等）全部 500。

修复：补上 await task_mgr.create_task(...)。复测：3 个阶段提交均 202 + 任务正常流转，0 崩溃。

⚠️ 待修复（本轮发现的其它真实问题）

B2 · 后端死路由 GET /api/director/stages/tasks

端点确实注册了，但运行时永远 404「阶段不存在」。根因：/{stage_id}（director_stage_api.py:49）注册在 /tasks（:201）之前，同为单段路径，后者被通配抢先匹配。修复：把 /tasks 的定义移动到 /{stage_id} 之前（或改路径）。

B3 · 前端 /script 白屏（React runtime error #310）

导航至 AI 剧本页主内容完全空白，控制台报 React 错误 #310（渲染期 hooks 数量不一致 / child missing）——条件分支中调用 hooks 导致。建议定位 ScriptPage.tsx 中按条件提前 return 后又使用 hooks 的代码路径。

B4 · 前端 /video 组件重复渲染

视频生成页存在两处 Tab 结构重复定义，且同样出现 React #310。布局异常但表单字段仍可识别。建议检查 VideoPage.tsx 的 Tab/Tabs 配置与 hooks 顺序。

七、结论与建议

后端整体健壮：126 个注册路由 + 数据层 CRUD + 批量编排 + 画布乐观锁 + 双 WebSocket 全部落地且 0 崩溃；生成链路因缺外部服务已验证为"优雅失败"而非崩溃。前端可正常构建，8 个主要页面 6 个通过。

建议按优先级处理：

  1. B3 / B4（前端 /script、/video 崩溃）——影响最大的可见问题，建议优先修复。
  2. B2（/stages/tasks 死路由）——一行级改动。
  3. 配置 ComfyUI / DeepSeek Key 后，对第六节功能做一轮「真实产出」回归。
  4. 把 python-multipart / opencv-python / numpy / PyYAML 补充进 requirements.txt（已确认必需）。
