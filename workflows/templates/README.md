# 多人分镜三元约束模板（T01-T10）

本目录存放多人分镜三元约束工作流所需的模板图片。每个模板由三张图组成：

- `{Txx_名称}_mask.png` — 蒙版图（人物区域分割）
- `{Txx_名称}_depth_clean.png` — 清场深度图（无人物的纯场景深度）
- `{Txx_名称}_pose.png` — OpenPose 骨架图（多人姿态绑定）

## 模板清单

| 编号 | 名称 | 描述 | 适用场景 |
|------|------|------|----------|
| T01 | 双人正面对话 | 两人面对面站立交谈 | 对话场景、采访 |
| T02 | 双人侧身对话 | 两人侧身相对 | 侧面构图对话 |
| T03 | 一前一后 | 一人前景一人背景 | 纵深构图、追逐 |
| T04 | 并肩行走 | 两人并肩前行 | 路上行走、同行 |
| T05 | 对坐交谈 | 两人对坐 | 餐桌、谈判、对弈 |
| T06 | 一人站立一人坐着 | 站坐姿态对比 | 指导、汇报、教学 |
| T07 | 拥抱 | 双人拥抱姿态 | 情感场景、重逢 |
| T08 | 握手 | 双人握手 | 商务、会面、和解 |
| T09 | 追逐 | 一人追一人 | 动作场景、追逐戏 |
| T10 | 群像构图 | 三人以上群像 | 群体场景、合影 |

## 使用方式

1. 手动在 ComfyUI 中使用 AIO_Preprocessor（DepthAnythingV2、OpenPose）生成深度图和姿态图
2. 使用图像编辑软件（Photoshop/Krita）绘制蒙版，标记每个人物占据的区域
3. 将三张图命名为上述格式，放入本目录
4. 在前端"多人分镜（三元约束）"弹窗中选择对应模板

## 工作流集成

模板文件由 [build_multi_person_workflow](../../backend/services/workflow_builder.py) 注入到 [多人分镜三元约束.json](../多人分镜三元约束.json) 工作流的 LoadImage 节点：

- 节点 3：模板蒙版
- 节点 4：清场深度图
- 节点 5：OpenPose 骨架

当缺少深度图或姿态图时，工作流构建器会自动移除对应的 ControlNet 节点并重连条件链，保证工作流可执行。
