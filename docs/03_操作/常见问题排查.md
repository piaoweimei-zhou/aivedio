# 常见问题与排查

> 独立排障手册，汇总导演工作台从启动到发布各环节的已知问题、成因与解决方式。操作手册第 7 节保留了精简版速查，本文是完整版。

---

## 1. 环境启动类

### 1.1 本机 Python 版本与项目锁定版本不兼容

项目锁定的 `fastapi==0.104.1 / pydantic==2.5.0` 只支持旧版 Python，而本机可用解释器仅 Python 3.13。直接 `pip install -r requirements.txt` 会失败。

解决：在 `backend/.venv-test` 隔离环境内使用 Python 3.13 + 最新版依赖自测，不影响项目锁定文件与全局环境。`requirements.txt` 需补齐运行时漏声明的 `opencv-python / numpy / PyYAML`。

### 1.2 旧版 Python 解释器路径损坏

历史遗留指向 `D:\1\python312\python.exe` 等的脚本会报 `CommandNotFoundException`。统一改用 `backend/.venv-test\Scripts\python.exe`，不要写死旧版本路径。

### 1.3 ComfyUI 未自动启动 / 图片请求 404

`GET /api/comfyui/image` 返回 404 通常是本地文件缺失或 ComfyUI 离线。确认两个启动脚本正确设置 `COMFYUI_DIR` / `COMFYUI_PYTHON`：`start_backend.bat` 会自动拉起 ComfyUI。

## 2. 任务 / 生成类

### 2.1 TTS 任务超时（300s），但实际几十秒就生成完

等待逻辑只轮询了 `images` 输出字段，漏掉音频的 `audio` 输出字段，导致一直在等已完成的产物。

解决：等待逻辑同时收集 `images` 与 `audio` 输出字段，audio 字段命中即判定完成。

### 2.2 TTS 音频 URL 无法下载（缺 subfolder）

音频文件存在子目录时，构造 `view` URL 缺少 `subfolder` 参数会取不到文件。

解决：在 URL 上按存储位置追加 `&subfolder=...`。

### 2.3 `_strip_workflow_meta()` takes 1 positional argument but 2 were given

该方法被当成实例方法调用，但使用方式要求它不依赖实例。

解决：给它加 `@staticmethod` 装饰器。

### 2.4 剧本风格意外改变（空 style_id 也注入默认风格）

概念图/分镜阶段在没有显式传 `style_id` 时也注入了风格，破坏向后兼容。

解决：仅当显式指定 `style_id` 时才注入风格，否则完全不动。

### 2.5 异步任务失败 / 未知状态

长时间任务异步执行，状态持久化在 `backend/data/task_state/`。任务失败先到「批量」页查看失败阶段与 `error` 字段，按提示补齐资源后重试；`GET /api/director/stages/task/{id}` 可查单任务状态。

### 2.6 路由 404：`/api/director/stages/tasks`

阶段子路由的参数匹配冲突导致 404。此类问题排查顺序：确认 vite 代理指向正确后端端口、后端已重启加载新路由、URL 路径参数是否被误匹配。

## 3. 视频处理（ffmpeg）类

### 3.1 `[WinError 5] 拒绝访问`（edit/compose/export/screen_record）

直接用 `FFMPEG_PATH` 环境变量解析 ffmpeg 可执行文件，在 Win 上因权限或路径不对而失败。

解决：统一用 `_ffmpeg_bin()` 解析正确的 ffmpeg 可执行路径。

### 3.2 ffmpeg 表达式报 `No option name near 'gte(...)'`

overlay 的坐标表达式叠加 `if()` 兜底会误导 filter 解析器。

解决：移除 `if()` 兜底，直接用指数衰减 + 正弦振荡表达式，并正确转义逗号（`gte(t\,26.20)`）。overlay 在 `enable` 时间窗之前不会求值坐标表达式，因此无需 `if()` 保护。

## 4. 字幕 / 编码类

### 4.1 字幕中文显示为乱码 / 问号

PowerShell 的 `Invoke-RestMethod` 会损坏 UTF-8 中文文本，导致字幕文本编码错误。

解决：改用 Python 编写的 `backend/output/temp/api_client.py`（UTF-8 安全）提交文本；后端 ASS 字幕使用中文字体（微软雅黑等）。

### 4.2 长字幕被截断 / 溢出

单行字符过多溢出画面。

解决：将字号从 48 调低到 34，并把长句按标点拆分为多行显示。

### 4.3 结尾钩子框贴底，被平台底部 UI 遮挡

钩子框 y 位于画面最底部，会被点赞/评论/操作栏盖住。

解决：默认按视频高度 10% 留白作为安全边距；`position` 可选 bottom/top/center，显式传 `margin` 时以用户值为准，极端小高度至少保留 1px。

## 5. 前端构建 / 运行时

### 5.1 antd `Card bordered` 弃用告警

antd 5 弃用 `bordered`，在 Compose/Graphic/Script/ScreenRecord 页替换为 `variant="outlined"`。antd 5.29.3 的 Descriptions 不支持 `variant`，其 `bordered` 不触发告警，保留即可维持表格边框。

### 5.2 React Router v7 Future Flag 告警

通过 `main.tsx` 开启 `v7_startTransition` 与 `v7_relativeSplatPath` 消除。

### 5.3 列表缺 `key` 告警

「Each child in a list should have a unique key」在 SettingsPage 出现，因表格列未与 API 返回字段对齐。

解决：让表格列与 API 返回的 `id/name` 对齐，并设置 `rowKey`。

### 5.4 生产构建 chunk 超过 500kB 告警

当前 JS 主包约 1.87MB（gzip 593kB）。优化方向：对 `OneClickVideoPage` 等大页面按路由 `React.lazy` 懒加载，并用 `manualChunks` 拆分 antd 等大依赖。属性能优化，不影响功能。

### 5.5 PowerShell 字符串插值语法错误

`"poll ${i}: $t.status"` 这种写法中，`$t` 会被解析为变量。用 `${t.status}` 包裹变量名消除歧义。提交信息请用 git 的多个 `-m`，PowerShell 不支持 heredoc `<<EOF`。

## 6. 密钥 / 供应商类

### 6.1 火山引擎图像生成尺寸校验失败

Seedream 4.5 要求总像素 ≥ 3,686,400。用官方推荐的 2K 尺寸映射：1:1 → 2048×2048、3:4 → 1728×2304、9:16 → 1600×2848，不要传过小的自定义尺寸。

### 6.2 视频模型（Seedance）未配置

火山引擎图片已接入（Seedream 4.5），视频模型（Seedance）复用同一 `ARK_API_KEY`，但需额外配置视频模型 Endpoint ID 才能调用。

### 6.3 密钥管理

所有密钥集中放在 `backend/.env`，前端只引用后端代理，不外发密钥。

## 7. 排查总则

1. **先看状态**：批量/任务页看失败阶段与 `error` 字段，前端控制台看报错栈。
2. **抓错分界**：用后端的 Python `api_client` 复现（避免 PowerShell 编码坑），确认是前后端接口还是本地工具（ffmpeg/ComfyUI）问题。
3. **资源就位**：多数生成类失败是模型/文件没到位（ComfyUI 离线、模型缺失、ffmpeg 路径错误），先排除再查代码。
4. **回归验证**：改完跑 `backend/.venv-test\Scripts\python.exe -m pytest` 与前端 `tsc --noEmit` / `npm run build`，再走一遍对应场景。
