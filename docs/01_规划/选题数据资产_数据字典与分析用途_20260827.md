# 选题数据资产：数据字典与分析用途 v1.0

> 日期：2026-08-27 ｜ 定位：把每日选题清单沉淀为**可分析、可追溯的数据资产**，为后续命中率复盘、热点趋势建模、爆款特征建模打基础。
> 关联：`主线选题系统_定位与双轨策略_20260827.md`（战略）→ 本文档（数据资产底座）

---

## 0. 为什么沉淀为资产

每日选题清单如果"用完即弃"，只能回答**今天**"什么火"；沉淀为带时间戳、带全量真实数据的历史快照后，就能回答：

- **命中率复盘**：我们选题库里的热点，做成内容发布后实际表现如何？（选题 → 生产 → 发布 → 数据回流）
- **热点趋势建模**：同一内容/类型的热度随时间如何涨落？（爆火窗口验证、追热点时机）
- **爆款特征建模**：什么标题/类型/时长/热度区间的内容容易爆？（为选题打分提供依据）
- **平台轮询基线**：多平台同一热点的横向对比（B 站 vs 抖音 vs 小红书 vs 快手）

**一句话：选题数据资产 = 飞轮的"数据积累层"，是选题打分和 ROI 计算的事实基础。**

---

## 1. 数据资产全景（四层沉淀）

| 层 | 存储 | 内容 | 回答的问题 |
|---|---|---|---|
| **信号层** | `data/signals.json` | tool-event：来源/关键词/热度/采集时间 | 工具触发了什么信号 |
| **选题库** | `data/topics.json` | 选题：标题/来源/自动打标/打分/状态 | 有哪些选题候选、分多高 |
| **快照层** | `data/selection/{YYYY-MM-DD}.json` | 当日全量真实数据：bvid/播放/点赞/评论/分享/收藏/热度/时间戳 | 某天哪些热点真实在火、多火 |
| **ROI 序列层** ⭐S3新增 | `data/roi/{video_id}.json` | 自产视频真实数据时间序列：每次轮询的播放/互动 | 自产视频发布后数据怎么涨（ROI/命中率） |

**快照层是热点趋势分析核心**（带全量真实数据+时间维度）；**ROI 序列层是飞轮闭环最后一环**（自产视频数据回流）。

## 2. 快照数据字典（`data/selection/{date}.json`）

```jsonc
{
  "date": "2026-08-27",          // 归档日期
  "updated_at": 1787829000,      // 本次更新 Unix 时间戳
  "items": [
    {
      "bvid": "BV1Uf8R6jEoC",    // 平台唯一标识（去重键）
      "platform": "bilibili",    // 平台
      "title": "杭州电梯猥亵案反转…", // 原标题（热点信号，非可搬运内容）
      "plays": 1011649,          // 播放量（真实）
      "likes": 139877,           // 点赞
      "comments": 0,             // 评论
      "shares": 0,               // 分享
      "collects": 0,             // 收藏
      "heat": 84.4,              // 热度分（可复算公式）
      "collected_at": 1787829000,// 采集时间戳
      "url": "https://www.bilibili.com/video/BV1Uf8R6jEoC"
    }
  ]
}
```

**关键设计**：
- **按日归档 + 同 bvid 去重合并**：一天多次采集只保留首次，避免重复；不同日期分别归档形成时间序列
- **全量真实字段**：播放/点赞/评论/分享/收藏齐全，可直接做互动率、增长量计算
- **heat 可复算**：热度公式与采集器 `_heat()` 一致，可对历史数据重算

---

## 3. 采集命令（生产快照的方式）

```bash
# 当日热门 15 条 → 解析 → 选题入库 + 沉淀当日快照
python -m app.collectors.collector --popular 15 --topics --snapshot data/selection --report
```

产出三件事：signals 信号、topics 选题入库、selection 当日快照。

---

## 4. 后续分析用途（数据积累够后）

| 分析 | 数据来源 | 产出 |
|---|---|---|
| **热点趋势** | 多日快照的同一 bvid/关键词 plays 序列 | 热点生命周期曲线、最佳发布时间窗 |
| **命中率** | topics(选题) → contract(生产) → publish(发布) → 数据回流 | 选题分与最终表现的相关性，迭代打分权重 |
| **爆款特征** | 快照全量字段统计 | 标题/类型/时长/互动率特征画像 |
| **平台对比** | 四平台采集快照 | 同一热点跨平台热度差异，平台适配依据 |

## 6. ROI 轮询器使用（S3）

```bash
# 指定自产视频 URL 轮询
python -m app.collectors.roi_poller --urls "https://...视频1,视频2" --roi-dir data/roi

# 从 publish_jobs.json 读 published 且 url 非空的自产视频
python -m app.collectors.roi_poller --jobs --roi-dir data/roi
```

**ROI 序列结构**（`data/roi/{video_id}.json`）：
```jsonc
{
  "video_id": "BV1Uf8R6jEoC",
  "url": "https://...", "platform": "bilibili", "title": "...",
  "first_seen": 1787823291, "last_seen": 1787823301, "sample_count": 2,
  "samples": [
    {"ts": 1787823291, "plays": 1034654, "likes": 143074, "comments": 0, "shares": 0, "collects": 0},
    {"ts": 1787823301, "plays": 1037995, "likes": 143109, "comments": 0, "shares": 0, "collects": 0}
  ]
}
```

**ROI 可算指标**：播放增速/点赞增速/互动率/发布时间窗口，与选题/生产/发布时间关联后即"命中率复盘"。
