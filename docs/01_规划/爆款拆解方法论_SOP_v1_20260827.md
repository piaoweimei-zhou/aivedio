# 爆款拆解方法论 SOP v1（可复用流程）

> 日期：2026-08-27 ｜ 状态：首拆星际外卖员（412万播放）完整跑通后固化
> 定位：把"如何拆解一支真实爆款"固化为**标准流程 + 工具链 + 输出模板 + 验收标准**，供批量拆解复用
> 关联：`hit_analysis/星际外卖员_拆解_画面.md`（首拆产物）＋ `爆款生产规范_v1`（拆解→生产规范反哺）

---

## 0. 一句话定位

**选真实爆款 → 下载 → 四维拆解（画面/台词/声音/情绪）→ 提炼公式 → 反哺生产规范。** 每支爆款一份拆解笔记，累积成"爆款公式库"。

---

## 1. 完整流程（7 步）

| 步骤 | 内容 | 工具/命令 | 验收 |
|---|---|---|---|
| S1 选品 | 从选题库/快照筛真实爆款（B站播放≥100万）| 选题库 topics.json、快照 selection/ | 选中的有真实播放/热度数据 |
| S2 下载 | 获取视频文件 | skill 统一入口 → 失败用 requests 兜底（见 §3 已知坑）| 本地 MP4 + 元数据 |
| S3 画面分析 | 抽关键帧（钩子/四分段/结尾）→ 读图 | ffmpeg 抽帧 + Read 看图 | ≥4 帧解读，含钩子帧 |
| S4 台词分析 | 转写逐字稿 → 结构/文案公式 | skill `--run-lark`（飞书妙记）| 全量逐字稿 + 场景时序 |
| S5 声音分析 | 响度曲线 → 配乐/情绪判断 | ffmpeg volumedetect 分段 | 整体响度 + 分段波动 |
| S6 公式提炼 | 四维→爆款公式（钩子/结构/文案/情绪/视觉/声音）| 拆解笔记 §7 | 公式 v{n} 可反哺 |
| S7 反哺规范 | 公式 → 生产规范（19 项映射+硬规则）| 更新《爆款生产规范》| 硬规则 ≤5 条可执行 |

---

## 2. 拆解笔记输出模板（每支爆款一份）

```
# 爆款拆解：{标题}
> 拆解日期 / 真实数据(播放/点赞/heat) / URL / 本地文件
## 0. 一句话结论
## 1. 关键帧时序（画面维度证据）
## 2. 结构节奏（场景时序）
## 3. 文案公式（台词维度）
## 4. 声音/情绪
## 5. 爆款公式 v{n}
## 6. 可反哺点
```

## 3. 已知坑（首拆实测，批量复用前必读）

| 坑 | 现象 | 应对 |
|---|---|---|
| skill 下载 SSL 失败 | urllib 拉 playurl 握手超时 | 用 requests（collector 已验证）拉 playurl |
| CDN 节点被网络干扰 | mountaintoys.cn SSL 断开 | 用 `backup_url`（bilivideo.com 官方节点）|
| 未登录清晰度限制 | 只能 quality 32(480p)/16(360p) | 分析够用，480p 即可 |
| DASH 分段 | fnval=16 时 durl 为空 | 用 `fnval=1` 拿整段直链 |
| 飞书转写授权 | 首次需授权 | 引导授权一次，之后自动 |
| 转写"not ready" | 妙记还在生成 | 稍后重读 transcript.txt |

---

## 4. 质量标准

- **选品**：真实播放 ≥100 万（无数据不拆）
- **分析**：钩子帧必须命中（0-5s）；台词需全量逐字稿；响度需整体+分段
- **公式**：每支至少产出"钩子/结构/文案/情绪"四维可反哺点
- **版权**：只提炼"元规律"（结构/节奏/情绪），不复制台词/画面/设定
