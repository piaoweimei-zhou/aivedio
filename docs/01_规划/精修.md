# 精修阶段 content_type 差异化改造计划

## 目标

将精修阶段（Qwen Image Edit 单图编辑）从当前的"一刀切"参数改为按内容类型（角色/场景/道具）自动差异化配置，核心改动在 `build_qwen_workflow()` 中收口。

## 核心差异

精修 vs 概念图的使用模型完全不同：

| | 概念图（文生图） | 精修（图生图） |
|---|---|---|
| 模型 | Z-Image 瑶光 | Qwen Image Edit + 一致性 LoRA |
| 输入 | 纯文本 prompt | 参考图 + 修改指令 |
| 输出 | 全新生成的图像 | 基于原图修改的图像 |
| 前端 UI | "画面描述"输入框 | "修改指令" + 源图预览 |

## 后端改动

### 文件 1：`backend/services/qwen_workflow.py` — `build_qwen_workflow()`

**新增参数：** `content_type: str = ""`

**注入节点覆盖逻辑（在提示词注入之后、保存之前）：**

```python
# ── content_type 驱动的精修参数定制 ──

_LORA_STRENGTH = {
    "character": 1.0,   # 锁死五官/肤色一致性
    "scene":     0.6,   # 允许光影突变
    "prop":      0.4,   # 允许材质完全推翻
    "":          1.0,   # 默认拉满
}

_SCALE_LENGTH = {
    "character": 1344,  # 竖屏角色全身
    "scene":     1344,  # 横屏场景广角
    "prop":      1024,  # 方形道具特写
    "":          1344,  # 默认
}

if content_type:
    ct = content_type
    # 1. LoRA 强度（节点 381: LoraLoaderModelOnly）
    for node_id, node_data in wf.items():
        if (isinstance(node_data, dict)
                and node_data.get('class_type') == 'LoraLoaderModelOnly'
                and 'strength_model' in node_data.get('inputs', {})):
            old = node_data['inputs']['strength_model']
            node_data['inputs']['strength_model'] = _LORA_STRENGTH.get(ct, 1.0)
            logger.info(f"[Qwen] content_type={ct} → LoRA节点{node_id} strength_model {old}→{node_data['inputs']['strength_model']}")
            break

    # 2. 缩放尺寸（节点 169: LayerUtility: ImageScaleByAspectRatio V2）
    for node_id, node_data in wf.items():
        if (isinstance(node_data, dict)
                and 'ImageScaleByAspectRatio' in node_data.get('class_type', '')
                and 'scale_to_length' in node_data.get('inputs', {})):
            old = node_data['inputs']['scale_to_length']
            node_data['inputs']['scale_to_length'] = _SCALE_LENGTH.get(ct, 1344)
            logger.info(f"[Qwen] content_type={ct} → 缩放节点{node_id} scale_to_length {old}→{node_data['inputs']['scale_to_length']}")
            break
```

**注意：** `instruction` 字段绝对不能改，保持工作流原始值。

## 前端改动

### 文件 6：`frontend-director/src/pages/AssetsPage.tsx` — 精修弹窗改造

**当前状态：** 纯文本输入弹窗，无图预览，无内容类型感知

**改后 UI 结构：**

```
┌─ Modal: 图生图 · 单图精修 ─────────────────┐
│                                              │
│  ┌─ 源图预览 ──────────────────────────┐    │
│  │  [ 被选中的图片预览 ]               │    │
│  │  名称: xxx  类型: [concept] [角色]   │    │
│  │  分辨率: 1024x1536                   │    │
│  └──────────────────────────────────────┘    │
│                                              │
│  内容类型: [角色]（从源资产自动继承）          │
│                                              │
│  ── 修改指令（prompt） ──                    │
│  ┌──────────────────────────────────────────┐│
│  │ 将原图中人物的xxx修改为yyy，保持脸部     ││
│  │ 特征和发型完全不变...                    ││
│  └──────────────────────────────────────────┘│
│  💡 提示：这是图生图，请写"改哪里、改成      │
│     什么样"的动词指令                        │
│     角色→保持脸部不变  场景→整体色调改为     │
│     道具→材质改为...                        │
│                                              │
│  ── 高级参数（可选展开） ──                  │
│  LoRA 一致性： 1.0（自动·角色）              │
│  Seed：        [固定] / [随机]               │
│  分辨率：      自动（按内容类型）             │
│                                              │
│  [取消]                    [开始精修]        │
└──────────────────────────────────────────────┘
```

**核心改动点：**

1. **源图预览区块** — 显示被选中的资产的图片、名称、类型双标签、分辨率
2. **内容类型指示** — 从源资产的 `content_type` 自动继承，显示为不可编辑的 Tag
3. **提示词输入框 placeholder** — 按内容类型动态切换：
   - 角色：`"将原图中人物的xxx修改为yyy，保持脸部特征和发型完全不变。写清楚改哪里、改成什么样"`
   - 场景：`"将原图的白天场景修改为xx场景，整体色调改为xx。必须强调保持场景结构不变"`
   - 道具：`"将原图中的材质从xx修改为yy，增加高光反射。必须写清楚材质改为什么"`
4. **提示词辅助提示** — 显示当期内容类型的"动词指令"写作指南
5. **高级参数区**（可选折叠）：
   - LoRA 一致性强度：按内容类型自动设定，可手动微调
   - Seed 策略：角色/道具→固定，场景→随机
   - 分辨率：自动按内容类型，可手动切换

**关键状态变量：**

```typescript
const [refineAsset, setRefineAsset] = useState<any>(null)  // 当前精修的目标资产
// 继承自源资产：
const refineContentType = refineAsset?.content_type || ''
const refineSourceType = refineAsset?.asset_type || ''
```

**精修请求参数：**

```typescript
params: {
  mode: refineMode,
  prompt: refinePrompt,
  content_type: refineContentType,  // ← 新增：传入源资产 content_type
}
```

## 数据流总览

```
前端弹窗
  ├─ 用户选中资产 A（asset_type=concept, content_type=character）
  ├─ 弹窗显示 A 的缩略图 + 双标签
  └─ 用户输入修改指令 + 点击"开始精修"
      ↓
refine_stage.execute()
  ├─ source = input_assets[0] (资产 A)
  ├─ content_type = source.content_type ("character")
  └─ _refine_via_comfyui(source, ..., content_type=source.content_type)
      ↓
ComfyUIProvider.refine_image(image_url, prompt, seed, content_type="character")
      ↓
comfyui_service.generate_refinement(..., content_type="character")
      ↓
build_refinement_workflow(..., content_type="character")
      ↓
build_qwen_workflow(content_type="character")
  ├─ 节点 381 LoRA strength_model → 1.0（角色）
  ├─ 节点 169 scale_to_length → 1344
  └─ 节点 180 prompt → 用户输入的修改指令
      ↓
ComfyUI 执行 → 输出精修后图片
      ↓
asset_svc.create(asset_type="edit", content_type="character")  → ✅ 角色精修图
```
