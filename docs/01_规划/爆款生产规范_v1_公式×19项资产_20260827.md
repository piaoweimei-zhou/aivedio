## 1. 爆款公式 v1（三维度摘要）

| 维度 | 公式要素 |
|---|---|
| 钩子 | 0-3s 画面悬念 + 3-5s 文案钩子（冲突/认知缺口）+ 第二人称代入 |
| 结构 | 单元式：一次旅程/主题串联 N 个场景，每 30-40s 一个新梗 |
| 文案 | 开场一句冲突+"一句话世界观"；荒诞×正经口吻；数据细节；主题留白 |
| 情绪 | 完整曲线：憋屈→温暖→爆笑→温情→余味 |
| 视觉 | 统一主色调 + 结尾对比色；角色稳定；常驻字幕 |
| 声音 | 匀速口播 + 恒定铺底乐（-17.6dB），情绪靠文案 |

## 3. 新增「爆款硬规则」清单（质量门禁 A 层用，≤5 条）

1. **钩子规则**：前 5s 必须同时命中"画面悬念 + 文案钩子（冲突/认知缺口）"
2. **单元规则**：中长片每 30-40s 至少 1 个新场景/新梗；单集单元数 5-8 个
3. **代入规则**：口播类默认第二人称"你"开场
4. **情绪规则**：全片情绪曲线必须完整（有低谷有高潮有收尾温度），禁止平铺
5. **字数规则**：台词密度 15-25 字/s，超限回炉精简
