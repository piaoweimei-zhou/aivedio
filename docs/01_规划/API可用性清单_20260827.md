## 1. 线上（火山方舟）三件套确认可用

- **文本**：`ep-2026081818...` chat 200 OK（3.2s）
- **图像**：`doubao-seedream-4-5` 1920×1920 生成 200 OK（10.9s）
- **视频**：`doubao-seedance` 5s 480p 16:9 生成成功，总耗时 **22s**（提交→轮询→完成），URL 在 TOS-CN-BEIJING

> ✅ 线上成片主力确认：火山文本/图像/视频三端全部真实可用，无需本地 GPU 也能成片（慢速但可行）。

## 2. 线下（ComfyUI 本地）

- ComfyUI 运行中：**NVIDIA GeForce RTX 5060 Ti / cudaMallocAsync / 17.1GB**（注：此前文档写 16GB，实测 17.1GB）
- MiniMax H3（本地 FL2VA 节点）依赖 ComfyUI → 文本→视频（含环境音），零 API 成本
- 约束不变：16-17GB 显存单实例，批量受限于本地 GPU

## 3. 已知坑（本次实测暴露）

| # | 坑 | 详情 | 应对 |
|---|---|---|---|
| 1 | **DeepSeek 欠费 402** | `Insufficient Balance`，OPENAI_BASE_URL=api.deepseek.com，OPENAI_TEXT_MODEL=deepseek-v4-flash | 充值 or 文本全部走火山 doubao；低成本选型表里 DeepSeek 最低价但当前不可用 |
| 2 | **seedream 图像尺寸下限** | `size` 必须 ≥ **3686400 像素**（1920×1920 起）；1024×1024 报 InvalidParameter 400 | 调用时统一用 ≥1920²，Provider `_normalize_size` 需复核该约束 |
| 3 | 文本 max_tokens=1 返回空 content | 200 但 content=''（非错误，是极短生成）| 正常，不影响可用性判断 |

## 4. 成本提示（结合低成本选型表）

- 视频 seedance 5s/480p 真实可跑 → 按元/秒计费（0.5-1.38 元/秒量级）
- 当前**成本最低路径**：文本/选题走火山 doubao（免费额度），成片视频走本地 MiniMax H3 / ComfyUI（零成本）
- 若需量产且 GPU 瓶颈：腾讯云 Kling 720P 0.3 元/秒、MiniMax Hailuo 0.225 元/秒 是候选（**尚未接入，需新增 provider**）

## 5. 建议下一步

1. **文本统一切火山 doubao**（DeepSeek 欠费期间唯一可用云端文本）
2. **图像尺寸约束**固化到 provider 层（`_normalize_size` 下限 3686400）
3. 成片管线默认走：LLM=火山 doubao，图像=本地 ComfyUI（大图）或火山 seedream（云端兜底），视频=本地 MiniMax H3（零成本）优先、火山 seedance 兜底
4. 低成本候选（腾讯云 Kling / MiniMax Hailuo API）待批量需求验证后接入
