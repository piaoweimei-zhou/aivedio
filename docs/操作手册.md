# 导演工作台 — 操作手册

> 面向视频创作者的实战指南。从启动环境开始，先用「一键成片」快速产出第一条可发布视频，再按需掌握单页手工制作、风格定制与发布技巧。

---

## 1. 启动环境

在 `backend/` 目录用 `.venv-test` 启动后端，前端用 Vite 开发服务器。ComfyUI 可由后端自动拉起（`start_backend.bat` 会设置 `COMFYUI_DIR` / `COMFYUI_PYTHON`）。

```powershell
# 后端（端口 8000）
cd backend
.\start_backend.bat

# 前端（端口 5174）
cd frontend-director
npm run dev
```

打开 `http://localhost:5174`。

首次使用前，先到「供应商设置」页补齐至少一个可用的生成供应商（本地 ComfyUI 或任一云端供应商的 API Key）。本地走 ComfyUI 时，确认模型文件已放入 ComfyUI 的模型目录（UNET / CLIP / VAE / LoRA）。

---

## 2. 快速上手：一键成片

适合第一次体验，只填一句话主题就能得到带配音、字幕、结尾钩子的完整竖版视频。

1. 进入「一键成片」页。
2. 在顶部输入**主题词**，选择**视频类型**，点击 **AI 生成剧本**。
3. 等待剧本生成完成，故事情节、台词、封面文案会自动填回下方表单。
4. 确认视频参数与素材槽位（默认多角色动态素材，也可直接用已有分镜图）。
5. 点击**一键成片**。系统依次执行：概念图 → 分镜 → 视频 → TTS 配音 → 剪辑合成 → 字幕 → 钩子 → 导出。
6. 完成后「成片结果」卡片出现预览视频，可播放确认字幕与钩子效果。

右侧面板的后期阶段（字幕 / 钩子 / 平台导出）默认开启，可单独关闭——关闭后仅生成原始长视频。

---

## 3. 分步手工：自定义想要的控制力

当主题直出不够精细时，可回到单页分步制作，手动控制每一步的提示词与素材。

### 3.1 产出素材

- 在「剧本」页输入主题，选择网感风格，生成分幕的故事情节、台词、封面文案与结尾钩子。
- 在「资产库 · AI 文生图」填 prompt、选内容类型（角色/场景/道具）生成概念图；右键可精修、超分、生成三视图、提取线稿/姿态/深度图。
- 在「图形」页做概念美术与氛围图。

### 3.2 分镜

到「分镜」页选定风格与角色/场景节点，生成分镜帧；或用无限画布自由搭建 ComfyUI 节点工作流。

### 3.3 成片

- 「视频生成」页选素材与供应商生成视频片段（标准或 MSR 多角色）。
- 「剪辑」页拼接、分段、加转场；「合成」页把多素材拼成一条。
- 需要配音时走 TTS（音色设计或音色克隆），音频会自动与画面混合。

### 3.4 字幕与钩子

- 「一键成片」或合成后的视频可烧录字幕，关键词可高亮（如钩子词）。
- 结尾自动叠加引导框——默认启用弹跳入场动效，醒目且不贴底（默认按视频高度 10% 留白，避免被平台底部 UI 遮挡）。

---

## 4. 网感风格

「剧本」与「分镜」页都有风格选择器，共 6 套：情感叙事、硬核干货、都市轻奢、治愈系、国潮国风、赛博科技。

选定风格后，脚本文案调性、概念图/分镜的视觉提示词会自动按该风格生成；未选择风格时行为与旧版本一致，不会改变既有流程。

---

## 5. 发布成片

### 5.1 多平台尺寸

「成片导出」页内置抖音、快手、视频号（1080×1920 9:16）与小红书（1080×1440 3:4）预设，一键套用分辨率/码率/命名后导出，均统一 H.264 + AAC。

### 5.2 发布素材包

在「一键成片」页出现成片后，进入「发布素材包」卡片：

1. 选一个**发布模板**（极简深色 / 活力橙 / 国风梨红 / 莫兰迪灰 / 赛博紫 / 暖棕治愈），封面配色、文案结构与标签会自动套用。
2. 微调成片标题、封面副文案、推荐标签。
3. 点击 **生成/刷新封面** 预览竖向封面。
4. 点击 **打包下载 (zip)**，一次获得：封面图 + 发布文案 txt + 成片视频；也可单独下载封面或文案。

确认成片画面中的字幕底部边距与结尾钩子边距，符合目标平台的 UI 安全区后再发布。

---

## 6. 供应商设置

各供应商的能力与密钥配置见下表，密钥都填在后端 `.env` 或「供应商设置」页：

| 供应商 | 用来做什么 | 需要配置 |
|--------|-----------|---------|
| ComfyUI（本地） | 文生图/精修/超分/分镜/视频/TTS | 模型文件就位即可 |
| 即梦 / RunningHub / Gemini / ModelScope | 云端补图/视频/三视图 | API Key |
| 火山引擎 | 图像（Seedream 4.5）+ 视频（Seedance） | ARK_API_KEY + Endpoint ID |

## 7. 常见问题

**Q：一键成片点后没反应/某阶段失败？**
到「批量」页查看该任务的阶段进度与失败原因；TTS、字幕等阶段失败多与本地 ComfyUI 模型或 ffmpeg 路径有关，按错误提示补齐后再重试。

**Q：下载的素材包 zip 里没有成片视频？**
成片较大或跨域导致浏览器无法直接读取时，zip 会自动降级为仅封面 + 文案，此时用「成片结果」卡片的单独下载成片按钮获取视频。

**Q：封面或字幕里的中文显示成乱码 / 问号？**
后端统一使用 UTF-8 与中文字体（微软雅黑等）渲染字幕；请通过后端的 API 客户端提交文本，避免 PowerShell 直发导致编码损坏。

**Q：怎么让导出的视频适配某个平台？**
在「成片导出」选对应平台预设即可；如需自定义，直接改分辨率/码率后导出。

---

## 8. 建议工作流

- **想快速出片**：一键成片（主题 → 全链路）。
- **想要更强控制**：剧本 → 手工出素材 → 分镜 → 视频 → 剪辑 → 字幕钩子 → 导出。
- **要批量投放不同平台**：先一键成片定稿，再在「成片导出」按平台预设各出一版，配合发布素材包一次性拿下封面与文案。
