# 导演工作台 — AI 视频生产管线系统

> 面向短剧/视频创作者的 AI 辅助全栈生产工具，覆盖从"主题/概念 → 剧本 → 资产生成 → 分镜 → 视频生成 → 配音剪辑 → 字幕钩子 → 多平台导出 → 发布素材包"的完整管线。

---

## 一、技术栈

| 层 | 技术 |
|---|---|
| 后端 | Python 3.13 + FastAPI + aiohttp + httpx |
| 前端 | React 18 + TypeScript + Vite + Ant Design 5 + Zustand + @xyflow/react + JSZip |
| AI 引擎 | ComfyUI（本地）/ 即梦 / RunningHub / 火山引擎（Seedream 图像 + Seedance 视频）/ ModelScope / OpenAI / Gemini |
| 数据 | 本地文件系统资产库 + Task 状态持久化 |

## 三、核心生产管线

### 1. 一键成片全链路（推荐入口）

从一句话主题直接得到可发布视频。DAG 编排分阶段执行，关键阶段自动串联：

```
主题/AI 剧本 → 概念图 → 分镜 → 视频生成 → TTS 配音 → 剪辑合成
→ 字幕烧录（关键词高亮） → 结尾钩子 → 多平台规格导出
```

- 由前端「一键成片」页提交，后端 `batch_api` + `dag_executor` 按阶段血缘自动调度
- 字幕 / 钩子 / 导出可单独开关，支持全链路或仅生成原始长视频
- 完成后前端自动定位最终视频资产用于预览与下载

### 2. 分步手工管线

```
文本描述 → 概念图 → 精修/超分 → 三视图 → 分镜 → 视频 → 剪辑 → 导出
```

| 阶段 | 功能 | 输入类型 | 输出类型 | 默认供应商 |
|------|------|---------|---------|-----------|
| **script** 剧本生成 | AI 生成分幕故事情节 / 台词 / 封面文案 / 钩子 | 无（文本） | script | ComfyUI |
| **concept** 概念图 | 文生图（角色/场景/道具） | 无（文本） | concept | ComfyUI |
| **graphic** 图形生成 | 图形/概念美术 | 无（文本） | image | ComfyUI |
| **refine** 精修/超分 | 图像增强 + 超分辨率 | concept/storyboard/edit | edit | ComfyUI |
| **angle** 三视图 | 正/侧/背面三视图 | concept（角色） | multi_view | ModelScope |
| **pano** 360 全景 | 全景图生成 | 无（场景） | pano | ComfyUI |
| **storyboard** 分镜 | 角色+场景融合生成分镜帧 | 无（角色+场景） | storyboard | ComfyUI |
| **video** 视频生成 | 图生视频 | storyboard/concept | video | 即梦 |
| **tts** 配音 | 文本转语音（音色设计/克隆） | 无（文本） | audio | ComfyUI |
| **edit** 视频剪辑 | 拼接、转场 | video | video | local |
| **compose** 合成 | 多素材拼接成一条视频 | video | video | local |
| **subtitle** 字幕 | 字幕烧录 + 关键词高亮 | video | video | local |
| **hook_overlay** 结尾钩子 | 引导框（弹跳动效） | video | video | local |
| **export** 成片导出 | 多平台尺寸/编码转换 | video | video | local |

### 内容类型驱动

每种内容类型自动切换不同的工作流模板和参数：

| 维度 | character（角色） | scene（场景） | prop（道具） |
|------|-----------------|-------------|-------------|
| 工作流模板 | 最终文生图.json（影视级） | 最终道具工作流.json | 最终道具工作流.json（专用） |
| 默认尺寸 | 1080×1920（竖版） | 1920×1080（宽屏） | 1920×1080（宽屏） |
| LoRA 强度 | 1.0 | 0.6 | 0.4 |
| 正向触发词 | 全身站立从头到脚 | 广角视角宏大场景 | 纯黑背景环形灯微距 |
| 精修约束 | 保持脸部特征 | 保持核心结构 | 保留轮廓，仅改材质颜色 |

## 四、网感风格（Style Registry）

通过 `style_registry.py` 定义 6 套短视频网感风格预设，覆盖脚本文案调性、视觉提示词与生成参数：

| 风格 | 脚本调性 / 视觉倾向 |
|------|--------------------|
| 情感叙事 | 口语化讲述、情绪递进，暖色调 |
| 硬核干货 | 结构化要点、数据支撑，冷色调高对比 |
| 都市轻奢 | 精致生活场景，高级灰调 |
| 治愈系 | 温柔舒缓节奏，柔光低饱和 |
| 国潮国风 | 传统文化元素，水墨/红金配色 |
| 赛博科技 | 未来感术语，霓虹紫青 |

- 注入时机：脚本阶段写入系统 prompt；概念图/分镜阶段附加视觉风格描述
- 保持向后兼容：仅当显式传入 `style_id` 时才注入，旧调用不变
- 前端「剧本」页与「分镜」页提供风格选择器，API 端点为 `GET /api/director/stages/styles`

## 七、模块化架构

### 1. 阶段插件体系（StagePlugin）

新增能力 = 注册一个 `StagePlugin` + 定义 `StageDef`（输入/输出类型、供应商），不动核心代码。阶段插件经拆分与新增后已达 30+ 个，由 `StageService` 统一调度。

### 2. 供应商插件体系（ProviderPlugin）

供应商实现统一的 `generate_image` / `generate_video` 接口，通过 `ProviderService` 按 ID 路由，上层业务无感知。火山引擎已接入 Seedream 4.5 图像模型与 Seedance 视频模型（复用 ARK 密钥）。

### 3. 异步任务队列（GenTaskManager）

长时间任务（精修/视频/TTS/MSR）异步提交，立即返回 task_id，前端轮询状态；任务状态持久化到磁盘，服务重启不丢失；并发数控制、超时自动失败、支持取消。

### 4. DAG 全链路编排（dag_executor）

按阶段输入输出的资产血缘自动推导执行顺序，支撑一键成片的多阶段串联与并行调度。

### 5. 巨型单文件拆分

将原单文件拆分以降低维护成本，对外 API 不变：

- `workflow_builder.py`（原 2433 行）→ 门面 + `workflow_core / character / scene / storyboard / helpers / params` 共 7 个模块
- `comfyui_service.py`（原 4606 行）→ 门面继承 5 个 Mixin：`comfyui_helpers / lifecycle / generation / video / storyboard / tts`

### 6. 资产注册表（AssetService）

所有生成结果统一注册为资产，支持版本化与血缘追踪（parent_id 链接上下游），标记内容类型（character/scene/prop）。
