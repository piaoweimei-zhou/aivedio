# 导演工作台 — AI 视频生产管线系统

> 面向短剧/视频创作者的 AI 辅助全栈生产工具，覆盖从"概念设计 → 资产生成 → 分镜制作 → 视频生成 → 剪辑导出"的完整管线。

---

## 一、技术栈

| 层 | 技术 |
|---|---|
| 后端 | Python 3.13 + FastAPI + aiohttp + httpx |
| 前端 | React 18 + TypeScript + Vite + Ant Design 5 + Zustand + @xyflow/react |
| AI 引擎 | ComfyUI（本地）/ 即梦 / RunningHub / 火山引擎 / ModelScope / OpenAI / Gemini |

## 三、资产生产阶段（8 个核心阶段）

从文本到成片的完整生产管线：

```
文本描述 → 概念图 → 精修/超分 → 三视图 → 分镜 → 视频 → 剪辑 → 导出
```

| 阶段 | 功能 | 输入类型 | 输出类型 | 默认供应商 |
|------|------|---------|---------|-----------|
| **concept** 概念图生成 | 文生图（角色/场景/道具） | 无（文本） | concept | ComfyUI |
| **refine** 精修/超分 | 图像增强 + 超分辨率放大 | concept/storyboard/edit | edit | ComfyUI |
| **angle** 三视图生成 | 正面/侧面/背面三视图 | concept（角色） | multi_view | ModelScope |
| **pano** 360全景生成 | 全景图生成 | 无（场景） | pano | ComfyUI |
| **storyboard** 分镜生成 | 角色+场景融合生成分镜帧 | 无（角色+场景） | storyboard | ComfyUI |
| **video** 视频生成 | 图生视频 | storyboard/concept | video | 即梦 |
| **edit** 视频剪辑 | 拼接、转场 | video | video | local |
| **export** 成片导出 | 编码/格式转换 | video | video | local |

### 内容类型驱动

每种内容类型自动切换不同的工作流模板和参数：

| 维度 | character（角色） | scene（场景） | prop（道具） |
|------|-----------------|-------------|-------------|
| 工作流模板 | `最终文生图.json`（影视级） | `最终道具工作流.json`（共用） | `最终道具工作流.json`（专用） |
| 默认尺寸 | 1080×1920（竖版） | 1920×1080（宽屏） | 1920×1080（宽屏） |
| LoRA 强度 | 1.0 | 0.6 | 0.4 |
| 正向触发词 | 全身站立从头到脚 | 广角视角宏大场景 | 纯黑背景环形灯微距 |
| 精修约束 | 保持脸部特征 | 保持核心结构 | 保留轮廓，仅改材质颜色 |

## 五、前端页面（6 个）

### 1. 资产库（AssetsPage）
核心页面，管理所有生成/上传的资产：
- **浏览筛选**：按资产类型（概念图/精修/三视图/全景/分镜/视频等）和内容类型（角色/场景/道具）过滤
- **AI 文生图**：填写 prompt → 选择内容类型 → 生成概念图
- **右键菜单**：精修、超分放大、生成三视图、提取线稿/姿态/深度图
- **重新生成**：用原 prompt 重新生成概念图
- **批量上传/删除/下载**

### 2. 分镜画布（StoryboardPage）
- **画布视图**：基于 @xyflow/react 的拖拽画布，角色/场景节点可自由摆放连线
- **无限画布**：嵌入完整的 canvas.html，支持 ComfyUI 自定义节点拖拽工作流
- **4 种运行模式**：文生图（text）、增强（enhance）、编辑（edit）、自定义工作流（custom）
- **自定义模式**：自动解析工作流 JSON 配置，生成对应输入表单（图片/文本框/滑块）

### 3. 视频生成（VideoPage）
- **标准视频生成**：选资产 → 填 prompt → 选择供应商/时长/比例/分辨率 → 提交
- **MSR 多角色视频生成**：选择 4 个角色参考图 + 背景图 + 全局提示词 + 分镜提示词
- 异步任务提交，前端轮询进度，完成后自动注册到资产库

### 4. 视频剪辑（EditPage）
- 视频拼接、分段、转场处理

### 5. 成片导出（ExportPage）
- 最终视频编码/格式转换导出

### 6. 供应商设置（SettingsPage）
- 管理各 AI 供应商的 API Key 和配置参数

## 六、无限画布（Infinite Canvas）

嵌入在分镜画布中的 ComfyUI 可视化节点编辑器，基于原生 canvas.html 实现。

### 核心特性
- **自由拖拽**：摆放 ComfyUI 节点到任意位置
- **节点连线**：支持输入/输出端口连接
- **级联运行**：节点按拓扑顺序自动执行
- **资产库集成**：可从资产库选择图片作为 LoadImage 节点输入

### 运行模式

| 模式 | 说明 | API 路径 |
|------|------|---------|
| text | 文生图（Z-Image 瑶光） | `/api/generate` |
| enhance | 图像增强 | `/api/generate` |
| edit | 图生图编辑 | `/api/generate` |
| custom | 自定义工作流（解析 JSON 配置） | `/api/generate` |

### 工作流配置格式

工作流 JSON 文件同目录下可放置 `.config.json` 配置文件，定义 UI 字段：

```json
{
  "title": "1人分镜",
  "fields": [
    { "id": "image_xxx", "node": "123", "input": "image", "type": "image", "name": "角色图" },
    { "id": "prompt_xxx", "node": "456", "input": "text", "type": "textarea", "name": "提示词" },
    { "id": "seed_xxx", "node": "789", "input": "value", "type": "number", "name": "种子" }
  ],
  "groups": [
    { "id": "images", "name": "参考图片", "layout": "grid" },
    { "id": "prompts", "name": "分镜提示词", "layout": "list" }
  ]
}
```

## 七、MSR 多角色视频生成

基于 LTX-2.3 模型的多人交互视频生成：

### 参数
| 参数 | 说明 | 默认值 |
|------|------|--------|
| 角色 1-4 参考图 | 4 个角色的外观参考图片 | （必填前 2 个） |
| 背景图 | 场景背景参考图 | 可选 |
| 全局提示词 | 场景描述（环境、氛围） | 必填 |
| 分镜提示词 | 每行一段角色动作描述 | 可选 |
| 分辨率 | 视频宽高 | 1280×720 |
| 帧数 | MSR 概念采样帧数 | 41 帧 |
| 总时长 | 视频总长度 | ~15 秒（361 帧@24fps） |

### 后端流程
```
接收请求 → 加载 MSR 工作流 → 注入参考图到 LoadImage 节点
→ 注入提示词到 PromptRelayEncode → 设置参数（INTConstant 节点）
→ 异步提交到 ComfyUI（_queue_prompt_with_retry）
→ 轮询等待完成（_wait_for_completion）
→ 下载视频到持久化目录 → 注册到资产库 → 前端显示播放
```

## 九、关键架构设计

### 1. 阶段插件体系（StagePlugin）
- 新增能力 = 注册一个 `StagePlugin` + 定义 `StageDef`（输入/输出类型、供应商），不修改核心代码
- 23 个阶段插件各自独立，通过 `StageService` 统一调度

### 2. 供应商插件体系（ProviderPlugin）
- 7 个供应商实现统一的 `generate_image` / `generate_video` 接口
- 通过 `ProviderService` 按 ID 路由，上层业务无感知

### 3. 异步任务队列（GenTaskManager）
- 长时间任务（精修/视频/MSR）通过异步任务提交，立即返回 task_id
- 前端轮询 `GET /task/{id}` 获取状态
- 任务状态持久化到磁盘，服务重启不丢失
- 并发数控制（默认 2 个并发），超时自动失败

### 4. 工作流构建器（workflow_builder）
- 根据内容类型（character/scene/prop）自动选择工作流模板
- 注入提示词、LoRA、尺寸、种子等参数
- Qwen/Z-Image 双路径支持

### 5. 资产注册表（AssetService）
- 所有生成结果统一注册为资产，支持版本化
- 资产血缘追踪（parent_id 链接上下游）
- 内容类型标记（character/scene/prop）

### 6. 无限画布 API 桥接（infinite_canvas_api）
- 将 canvas.js 期望的 `/api/*` 端点映射到现有后端服务
- 支持画布 CRUD、资产库、工作流执行、文件上传等
- ComfyUI 输出文件持久化到独立目录，不受定时清理影响
